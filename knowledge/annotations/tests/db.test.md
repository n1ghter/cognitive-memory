### Semantic Summary
#### DatabaseManager & Utils Tests

This file contains tests for the `DatabaseManager` class and its utility functions. The purpose of these tests is to ensure that:

- Valid UUIDs are generated by the `generateId` function.
- Record IDs are normalized correctly across different data types.
- The in-memory database can be initialized successfully.
- Custom memory database paths from environment variables are used when set.

Tests also cover fallback behavior for non-string representations of record IDs and usage of `MEMORY_DB_PATH` environment variable.
