### Search Tool

The search tool executes a memory search using an input query and optional parameters (limit and threshold). It converts the query text into its vector embedding, queries SQLite to retrieve matching items, and updates access statistics for returned results. This tool is part of the MCP suite.

**Interacts with:**

- SQLite tables (`memory` table)
