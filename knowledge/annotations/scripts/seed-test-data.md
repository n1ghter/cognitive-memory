# Semantic Summary: Seeding Test Data

This script seeds test data into the Local and Global databases, creating nodes and edges for a simulated network. The purpose is to populate these databases with initial data for testing purposes.

### MCP Tools Exposed:
- SQLite (executing SQL queries)
- SQLite Database Manager (managing database connections)

The seeding process involves inserting node metadata and embeddings into memory and vector memory tables, as well as creating edges between nodes.
