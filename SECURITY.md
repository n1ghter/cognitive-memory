# Security Policy

## Supported Versions

Currently, only the latest version of the `cognitive-memory` MCP server is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please DO NOT open a public issue. 

Instead, please send an email to the project maintainers or use the GitHub Security Advisories feature to privately report the issue. 

We will investigate all reports and do our best to quickly fix the problem and release an updated version before public disclosure.
